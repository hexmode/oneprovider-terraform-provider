* OneProvider Terraform Provider
:PROPERTIES:
:CUSTOM_ID: oneprovider-terraform-provider
:END:
This is a Terraform provider for [[https://oneprovider.com][OneProvider]], built on the [[https://github.com/hashicorp/terraform-plugin-framework][Terraform Plugin Framework]].

** Features
:PROPERTIES:
:CUSTOM_ID: features
:END:
- *Server Management* - Read and manage dedicated servers
- *VM (OneCloud) Management* - Create, manage, and control VMs
- *SSH Keys* - Manage SSH keys for VM access
- *Images* - Create and manage VM images (like AWS AMI)
- *Reverse DNS* - Manage RDNS entries for IPs
- *Configuration* - Query available configurations, sizes, templates, and locations

** Requirements
:PROPERTIES:
:CUSTOM_ID: requirements
:END:
- [[https://developer.hashicorp.com/terraform/downloads][Terraform]] >= 1.0
- [[https://golang.org/doc/install][Go]] >= 1.25

** Usage
:PROPERTIES:
:CUSTOM_ID: usage
:END:
#+begin_src hcl
provider "oneprovider" {
  api_key    = "your-api-key"
  client_key = "your-client-key"
}

# Create a VM
# Note: location_id, instance_size, and template are IDs returned by the OneProvider API.
# Use data.oneprovider_configuration.all.* to list valid values.
resource "oneprovider_vm" "example" {
  hostname      = "myvm.example.com"
  location_id   = 6
  instance_size = 108
  template      = "909"
}

# Manage SSH keys
resource "oneprovider_ssh_key" "deploy_key" {
  name  = "deploy-key"
  value = "ssh-rsa AAAA..."
}

# Set reverse DNS using the VM's IP address
resource "oneprovider_rdns" "example" {
  ip_address = oneprovider_vm.example.ip_addr
  domain     = "myserver.example.com"
}
#+end_src

#+end_src

** Developing the Provider
:PROPERTIES:
:CUSTOM_ID: developing-the-provider
:END:
#+begin_src shell
# Run unit tests
make test

# Run linter
make lint

# Generate documentation
make generate

# Run acceptance tests (requires API credentials)
make testacc
#+end_src

Note: Acceptance tests create real resources and cost money to run.
